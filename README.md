# 🧮 Basic Calculator

Welcome to my first C++ programming project! 🎉

This is a simple, beginner-friendly calculator developed
using C++. It performs basic mathematical operations and
helps practice programming fundamentals.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Power (Exponentiation)
- 🖥️ User-friendly console interface

## 🛠️ Technologies Used

- **Programming Language:** C++
- **Compiler:** Any standard C++ compiler
- **Library:** iostream, cmath

## ▶️ How to Run

1. Download or clone this repository.
2. Open the `calculator.cpp` file.
3. Compile the program using a C++ compiler.
4. Run the program in your terminal.
